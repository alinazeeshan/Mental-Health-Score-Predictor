🧠 Mental Health Score Predictor

A Machine Learning web application that predicts the mental health score of students based on various input factors. The project uses a trained machine learning model and provides an interactive web interface for users to enter their information and receive a prediction.

🚀 Live Demo

👉 "Try the Live Demo" (https://mental-health-score-predictor-1-2862.onrender.com)

💻 GitHub Repository

👉 "View Source Code" (https://github.com/alinazeeshan/Mental-Health-Score-Predictor)

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- FastAPI
- HTML
- CSS
- JavaScript
- Render

🤖 Machine Learning

The project follows a typical machine learning workflow:

- Data preprocessing
- Exploratory Data Analysis
- Feature preparation
- Model training
- Model evaluation
- Prediction
- Deployment as a web application

🌐 Deployment

The application is deployed using Render and can be accessed through the live demo link above.

📌 Project Features

- Interactive web interface
- Student mental health score prediction
- Machine learning-based prediction
- FastAPI backend
- Responsive frontend
- Online deployment

📂 Project Purpose

The goal of this project is to demonstrate how a machine learning model can be integrated with a web application and deployed online for real-time predictions.
